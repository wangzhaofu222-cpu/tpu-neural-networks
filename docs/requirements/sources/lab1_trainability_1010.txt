5.1   Многослойная сеть

Базоваямодель—полносвязнаясеть(многослойныйперцептрон).Слойсномеромl
берётвыходпредыдущегослоя,умножаетегонаматрицувесов,прибавляетсмещение,
нормализуетиприменяетфункциюактивации:

         z(l)  =W    (l) h(l−1)    +b   (l) ,       h(l)  =ϕ (︁Nl(z  (l) ))︁,       l= 1,...,L,       (1.1)

где
  •h  (0) =x—входсети,h(l)  ∈R   nl—выходслояl, nl—ширинаслоя(числонейронов);
  •W   (l)  ∈R   nl×n  l−1  иb  (l) —весаисмещения;
  •z  (l) —значениядофункцииактивации(pre-activation);
  •N  l—нормализация:еёнет,BatchNormилиLayerNorm(раздел5.4);
  •ϕ—функцияактивации,применяемаяккаждомуэлементу;
  •L—глубина,числоскрытыхслоёв.
Порядок«нормализация,затемактивация»фиксируетсявконфигурациииодинаков
длявсехсравниваемыхсетей.

5.6   Как измерять обучаемость

Итоговойточностидлявыводаобобучаемостинедостаточно.Длякаждогозапуска
измеряютсячетыревеличины.
    Уровеньошибкипослеобучения.Модель,котораяугадываетклассслучайно,
имеетошибку(cross-entropy)lnK ,гдеK—числоклассов;дляK = 10этопримерно2,3.
СравнимснимошибкупослеTшаговобучения:

                           ρT = LTlnK   ,                             (1.14)

гдеLT—ошибканафиксированномподмножествеобучающихданныхпослеTшагов.
Сетьсчитаетсяобучаемой,еслиρT ≤ 0,5,инеобучаемой,еслиρT ≥ 0,9;промежуточные
значения—пограничныйрежим.
    Размер градиента в слое.Чтобысравниватьслоиразногоразмера,норму
градиентаделятнакореньизчислапараметров:
                             ⃦⃦∇θlL⃦⃦2
                          gl =√︁|θ l|  ,                            (1.15)


гдеθl—параметрыслояl,|θ l|—ихчисло.Вовремяобученияберётсямедианаglпо
измеряемымшагам.
    Дисбаланс градиентов между слоями:

                       GI = log10 maxlgl+εminlgl+ε   .                        (1.16)

ЗначениеGI = 1означает,чтоградиентыслоёвразличаютсяв10раз,GI = 3—в1000
раз.
    Изменение разброса активаций с глубиной:
                AVD = maxl⃓⃓log10(v l+ε)−log            10(v 1+ε)   ⃓⃓,                (1.17)


гдеvl—дисперсияактивацийслояlнапробномbatch,ε = 10−12  —константадля
защитыотлогарифмануля.

7   Индивидуальный профиль

НачинаясЛР1,параметрыкаждойработывычисляютсяизотдельногохеша:номера
зачёткивместесномеромработы.Поэтомупрофилиразныхработнезависимы.Добавьте
вгенераторпрофиляизЛР0функциюlab_pickитриполяЛР1:
def  lab_pick(student_id:  str, lab: int, a:  int,  b:  int,  options:  list):
   hk  =  hashlib.sha256(f"{student_id}:lab{lab}".encode("utf-8")).hexdigest()
   return  options[int(hk[a:b],  16)  % len(options)]

profile["lab1_depths"]  =  lab_pick(sid,  1,  0,  2, [[4, 16,  32,  64],  [8,  24,  48,  96]])

profile["lab1_bad_sigma"]  =  lab_pick(sid,  1,  2,  4,  [0.02,  0.05,  0.10])
profile["lab1_optimizer"]  =  lab_pick(sid,  1,  4,  6,  ["sgd_momentum",  "adamw"])
