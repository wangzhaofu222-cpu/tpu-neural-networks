# Lab 0 — официальный отчёт

Итоговый документ: `Lab0_Report.pdf`. Только Lab 0; новые обучения не выполняются.

## Компиляция

Открыть эту папку и выполнить `./build.ps1` в PowerShell. Скрипт использует XeLaTeX
из уже установленного TeX Live 2026, компилирует титульный лист и основной документ,
затем копирует PDF в итоговое имя. Устанавливать пакеты или менять системные настройки
не требуется. Для сборки достаточно шрифтов Times New Roman, Arial, Consolas и SimSun.

Ручная сборка: `latexmk -xelatex -interaction=nonstopmode -halt-on-error main.tex`.
При изменении титульного листа сначала выполнить ту же команду для `title_page.tex`.

## Состав исходников

- `main.tex` — преамбула и включение единственного титульного листа.
- `report_body.tex` — шесть обязательных разделов, источники и приложение.
- `title_page.tex` — новые поля поверх очищенной основы исходного шаблона.
- `assets/title_base.pdf` — исходные неизменённые элементы, включая логотип;
  операторы вывода старого названия работы, дисциплины, звания и имени преподавателя удалены.
- `figures/` — шесть графиков в PDF/PNG; седьмой рисунок — схема TikZ в тексте.
- `tables/` — таблицы, вычисленные из сохранённых результатов; CSV служат копиями данных.

Для будущей работы в `title_page.tex` меняются `LabNumber`, `LabTitleFirst` и
`LabTitleSecond`. Другие отчёты сейчас не создавались.

В автономном архиве для компиляции используется `build.ps1`. Вспомогательные
Python-скрипты проверок и пересчёта рассчитаны на исходный проект с его журналами,
контрольными точками и Python-окружением; они не требуются для сборки PDF.

## Сохранение исходных материалов

Оригинальный `Тулист.pdf` в корне проекта не изменяется. Предыдущий `main.tex`
сохранён побайтово в `previous_report/main.tex`; предыдущий `report.pdf`,
`report.ru.md`, численные результаты и изображения `images/` оставлены на местах.
Новый официальный отчёт не заменяет эти исторические материалы.

Приложение содержит полные RUN_ID. Пересчёт рисунков и таблиц из первоначальных
журналов реализован в `tools/build_report_assets.py`; проверка сохранённых параметров
в `tools/audit_checkpoint_results.py` не обучает модели. Итоги численной и визуальной
проверки хранятся отдельно от официального текста в `build/`.
